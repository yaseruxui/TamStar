# سبارك كودرز — الموقع التعريفي (skodr.com)

موقع ثابت بالعربية (RTL) وبثيم داكن، مبني من الصفر بهوية سبارك كودرز.

## التشغيل

افتح `index.html` عبر أي خادم ثابت، مثلًا:

```bash
python3 -m http.server 8080
```

## الهيكل

```
index.html            الصفحة (كل الأقسام)
assets/css/fonts.css  تعريف الخطوط المحلية
assets/css/styles.css الهوية والتنسيقات (المتغيرات في :root)
assets/js/main.js     سكربت محلي واحد بلا مكتبات
assets/fonts/         Alexandria + IBM Plex Sans Arabic (رخصة SIL OFL)
assets/img/logo-mark.svg  الشعار (إعادة رسم مؤقتة — استبدله بالملف النهائي بنفس الاسم)
```

## الألوان (من الشعار)

| المتغير                         | اللون                             | الاستخدام             |
| ------------------------------- | --------------------------------- | --------------------- |
| `--violet`                      | `#B26CFF`                         | بداية التدرج، التمييز |
| `--plum`                        | `#6E29AC`                         | التدرجات الهادئة      |
| `--ocean`                       | `#0C8EC7`                         | التدرجات، الشارات     |
| `--aqua`                        | `#7FEEFA`                         | الروابط، حالة التركيز |
| `--ink` / `--ink-2` / `--ink-3` | `#07051A` / `#0E0A26` / `#17123A` | الخلفيات الداكنة      |

## الأمان والنظافة

- لا يوجد أي سكربت أو خط أو ملف CSS من موقع خارجي؛ سياسة CSP في `<head>` تمنع ذلك (`script-src 'self'`).
- النماذج تتحقق محليًا فقط؛ اربطها بخادمكم (أو endpoint على نفس النطاق) قبل الإطلاق.

## محتوى يجب استبداله قبل النشر

- أسماء وصور أعضاء الفريق (`اسم عضو الفريق`).
- آراء العملاء (`اسم العميل — المنصب، اسم الشركة`).
- المشاريع وروابطها، روابط التواصل الاجتماعي، رقم الهاتف.
- الشعار النهائي في `assets/img/logo-mark.svg`.
